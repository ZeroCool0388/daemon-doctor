# Daemon Doctor

Watches the apps and background services on a Mac, spots when one is down, stuck, or hogging the machine, explains it in plain English, and fixes it only after you approve. Fixed rules only: no AI in the decision or fix path. Zero running cost.

**Status:** early build. See [docs/plan.md](docs/plan.md) for the full plan.
